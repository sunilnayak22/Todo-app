# Todo App

A simple Todo Application built to practice backend development and understand how frontend and backend communicate using REST APIs.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Features

- Add new todos
- Display all todos
- Delete todos
- Fetch data from backend APIs
- JSON-based data communication

## API Routes

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/todos` | Get all todos |
| POST | `/api/todos` | Add a new todo |
| DELETE | `/api/todos/:id` | Delete a todo |

## Installation and Setup

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd todo-project
```

3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
node server.js
```

5. Open in your browser:

```text
http://localhost:3000
```
